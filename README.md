# 🏡 Real Estate Data Transformation & Analysis — Properati Argentina

This project demonstrates how **raw and inconsistent real estate listing data** can be transformed into a **structured dataset** suitable for **statistical analysis, visualization, and predictive modeling**.

The analysis uses **Properati Argentina real estate listings**, with a specific focus on **properties in Capital Federal priced above USD 500,000**.

## 📊 Project Deliverables

The project produces **two complementary deliverables**, both based on the same cleaned and processed dataset:

1. **Data Transformation Workflow** – An end-to-end pipeline for parsing, cleaning, transforming, and preparing raw property listings for analysis.

2. **Analytical Insights** – Statistical analysis, exploratory visualizations, geographic analysis, and predictive modeling applied to the curated dataset.
