🏡 Real Estate Data Transformation & Analysis (Properati Argentina)
This project demonstrates how raw, inconsistent real estate listing data can be transformed into a structured dataset suitable for statistical analysis, visualization and predictive modeling.

The analysis focuses on real estate listings in Argentina (Properati data), specifically Capital Federal properties priced above USD 500,000.

📊 Project Deliverables
The project produces two complementary deliverables, both built on the same parsed dataset:
Data Transformation Workflow – end-to-end pipeline for cleaning, structuring and preparing raw listings for analysis.

Analytical Insights – statistical exploration, visualizations and predictive modeling applied to the curated dataset.
