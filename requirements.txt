## Requirements

* **Python 3**: Core execution environment.
* **Pandas**: Data manipulation, cleaning, and tabular data structuring.
* **NumPy**: Numerical operations and array handling.
* **SciPy**: Advanced statistical testing and mathematical functions.
* **Scikit-learn**: Machine learning model building, evaluation metrics, and feature transformations.
* **Category Encoders**: Advanced categorical feature encoding techniques.
* **Seaborn**: Statistical data visualization.
* **Matplotlib**: Core plot customization and base visual generation.
* **Plotly**: Interactive charting and exploratory data visualizations.
* **Power BI**: Spatial mapping, interactive dashboard creation, and final reporting.
